# TJC8048X550_011R 畫面檔製作步驟

這份文件帶你在 TJC 的 **USART HMI** 編輯器裡，把 `layout.json` 的設計做成 `.HMI`／`.tft`。
照著做就好，不需要再決定任何版面。全部 9 頁、63 個元件，熟的話一小時內可以做完。

先說三件事：

- **這台電腦沒有裝 USART HMI。** `下載` 資料夾裡的 `nextion-setup-v1-67-1.exe` 是 Nextion Editor，
  它不能開 TJC 的型號，做出來的 `.tft` 也不能燒進 TJC 螢幕，不要用。
- 因為沒裝編輯器，下面的**選單與屬性名稱是照 TJC 官方文件寫的，沒有在實機上逐一核對**。
  編輯器是簡體中文介面，文中用「」標出畫面上的簡體字樣；位置若有出入，以屬性名稱（`objname`、`txt_maxl` 這類英文名）為準。
- 這個畫面**還沒有在實體螢幕上跑過**。做完請照第 9 節的清單測。

元件名稱（`objname`）、頁面名稱一個字都不能錯，大小寫也要一樣。
MMDVM 是用名稱找欄位的，名稱錯了那一格就是空白。

---

## 1. 安裝編輯器

1. 到淘晶馳官網（tjc1688.com）的「資料下載」下載 **USART HMI** 最新版並安裝（只有 Windows 版）。
2. 開啟後若詢問更新，更新到最新版。X5 系列需要較新的版本才選得到。

## 2. 新建專案

1. 「文件」→「新建」，檔名存成 `tjc8048x550_mmdvm.HMI`，放在這個目錄（`display/tjc8048x550/`）。
2. 「设备」頁籤：系列選 **X5**，型號選 **TJC8048X550_011R**（800×480，電阻觸控）。
3. 「显示」頁籤：
   - 顯示方向：**橫向，0 度**（800 寬 × 480 高）。
   - 字元編碼（「字符编码」）：**iso-8859-1**。

   > 為什麼不用預設的 GB2312：MMDVM 送溫度時「°」是單一位元組 0xB0。GB2312 會把它當成中文字的前半個位元組，
   > 連後面的 `C` 一起吃掉變成亂碼。iso-8859-1 裡 0xB0 就是「°」。代價是這個畫面不能顯示中文，第一版先這樣。
   >
   > 如果下拉選單裡真的沒有 iso-8859-1：改選 GB2312，字型也用 GB2312 做，然後照第 5 節最後的「備案」多貼四行程式碼。

4. 按「OK」。編輯器會自動建立一個 `page0`。

## 3. 匯入圖片（順序就是圖片 id）

左下角「图片」頁籤，按「+」，**一次選一個檔、照下表順序**加入（一次全選的話順序不保證）。
加完後確認每張圖左邊顯示的編號跟下表一樣；不一樣就刪掉重加。

| 圖片 id | 檔案（`resources/`） | 用在哪一頁 |
|---|---|---|
| 0 | `00_bg_MMDVM.png` | MMDVM |
| 1 | `01_bg_DStar.png` | DStar |
| 2 | `02_bg_DMR.png` | DMR |
| 3 | `03_bg_YSF.png` | YSF |
| 4 | `04_bg_P25.png` | P25 |
| 5 | `05_bg_NXDN.png` | NXDN |
| 6 | `06_bg_POCSAG.png` | POCSAG |
| 7 | `07_bg_FM.png` | FM |
| 8 | `08_bg_System.png` | System |

每張都是 800×480 的整頁背景，標題列、面板底色、`RX`／`TX`／`RSSI`／`BER` 這些固定文字都已經畫在圖裡，
所以編輯器裡只需要放「會變的欄位」。

## 4. 製作字型（順序就是字型 id）

「工具」→「字库制作」。共做 4 個，**照順序做、照順序加入專案**：

| 字型 id | 名稱 | 字高 | 編碼 | 字體 | 用途 |
|---|---|---|---|---|---|
| 0 | `F32` | 32 | iso-8859-1 | Consolas，粗體 | 時鐘、IP、底部小欄位、SYS 按鈕 |
| 1 | `F48` | 48 | iso-8859-1 | Consolas，粗體 | 狀態列、頻率、RSSI／BER、Talker Alias、POCSAG 訊息、System 頁按鈕 |
| 2 | `F72` | 72 | iso-8859-1 | Consolas，粗體 | DMR 來源與 TG、目的地 |
| 3 | `F96` | 96 | iso-8859-1 | Consolas，粗體 | 待機頁的呼號、單一通話頁的來源呼號 |

每個字型的做法：

1. 「字高」填表中數字；「编码」選 **iso-8859-1**（要跟專案編碼一樣，不然編譯會報錯）。
2. 字體選 **Consolas**、勾粗體。Consolas 是 Windows 內建的等寬字型；沒有的話用任何一種粗的等寬字型都可以。
   一定要等寬：版面是照「每個字寬 = 字高的一半」算的（16／24／36／48 px）。
3. 「字库名称」填表中名稱，按「生成字库」，存成 `F32.zi` 這類檔名。
4. 關閉視窗時編輯器會問要不要加入專案，選「是」。或到左下角「字库」頁籤按「+」加入。
5. 四個做完後，「字库」頁籤裡的編號應該是 0=F32、1=F48、2=F72、3=F96。順序錯了就全部刪掉照順序重加。

## 5. 建立頁面與元件

### 通則

- **頁面：** 右上「页面」窗格按「+」新增，然後改名。頁面順序必須是
  `MMDVM`(0)、`DStar`(1)、`DMR`(2)、`YSF`(3)、`P25`(4)、`NXDN`(5)、`POCSAG`(6)、`FM`(7)、`System`(8)。
  `MMDVM` 一定要是第 0 頁（把自動建立的 `page0` 改名成 `MMDVM`），螢幕上電顯示的就是它。
- **頁面背景：** 點頁面空白處，屬性窗格 `sta` 選「图片」，`pic` 填該頁的圖片 id。
- **放元件：** 從左邊工具箱點一下元件類型就會出現在頁面上，然後在右下屬性窗格填值。
  **照表格由上到下的順序放**，元件 id 就會跟表格的 id 欄一樣（id 只影響疊放順序，MMDVM 不用 id，但照順序最不會亂）。
- **每個元件要填的屬性**（表格的欄位名稱就是屬性窗格的名稱）：

  | 屬性 | 說明 |
  |---|---|
  | `objname` | 元件名稱，照表格填，大小寫一致 |
  | `vscope` | 表格寫 **global** 的選「全局」，其餘維持「私有」 |
  | `sta` | 文字、數字、按鈕都選「单色」（純色背景） |
  | `bco` / `pco` | 背景色／文字色，直接填表格裡的十進位數字（RGB565） |
  | `font` | 字型 id |
  | `xcen` | 0 靠左、1 置中、2 靠右 |
  | `ycen` | 0 靠上、1 置中、2 靠下 |
  | `txt` | 初始文字；表格寫（空白）就清空 |
  | `txt_maxl` | 字串最大長度，**一定要照表格改**。預設值很小，不改的話 MMDVM 送來的字會被截掉 |
  | `x` `y` `w` `h` | 位置與大小 |

- **類型對照：** 文本 = Text、数字 = Number、按钮 = Button、变量 = Variable、定时器 = Timer、触摸热区 = Hotspot。
  「变量」和「定时器」不會出現在畫面上，會列在頁面下方的灰色區域。
- **`S0`：** 每一頁都要有。放一個「触摸热区」，把 `objname` 從 `m0` 改成 **`S0`**（大寫 S、數字 0），
  位置大小照表格（右上角 8×8，看不到也按不到）。程式碼貼在它的「**按下事件**」，不是彈起事件。
- **貼程式碼：** 選取元件，在下方事件窗格切到指定的事件頁籤，把程式碼整段貼上。
  `if(...)` 括號裡不可以有空格，`{`、`}` 各自一行；直接複製貼上就不會錯。
- **省時間：**
  - 同一頁可以先放好所有「文本」，框選多個後一次改 `sta`、`bco`、`font`。
  - `P25` 做好後，在「页面」窗格對它按右鍵「复制」，改名成 `NXDN`，再改 `pic` = 5 和 `S0` 的程式碼（數字不同）。
  - `YSF` 也可以從 `P25` 複製再改。
- **色碼對照**（都是 RGB565 十進位）：

  | 數值 | 顏色 | 用途 |
  |---|---|---|
  | 0 | 黑 | 頁面底色 |
  | 6405 | 深藍灰 | 面板底色 |
  | 10664 | 藍灰 | 標題列、待機頁底部列 |
  | 65535 | 白 | 主要文字、通話中 |
  | 52858 | 淺灰 | 次要文字 |
  | 33906 | 灰 | Listening（守聽中） |
  | 65056 | 琥珀 | TG、目的地、CW |
  | 18190 | 綠 | MMDVM IDLE |
  | 64073 | 紅 | ERROR／LOCKOUT／STOPPED |
  | 18015 | 青 | Talker Alias、D-Star 訊息 |
  | 12943 | 藍 | 按鈕 |

## 6. 編譯

1. 按工具列「编译」。下方輸出窗格最後要是 0 個錯誤。
2. 常見錯誤：
   - 「字库编码与工程编码不一致」：某個字型不是 iso-8859-1，回第 4 節重做那一個。
   - 找不到 `MMDVM.status`：`MMDVM` 頁的 `status` 變數沒建，或 `vscope` 沒設成「全局」。
   - 找不到 `t1`／`t2` 之類：那一頁少放了元件，或 `objname` 打錯。
3. 按「调试」開模擬器看一下。在模擬器下方的指令輸入框可以手動送指令測試，例如：

   ```
   page DMR
   t2.txt="2 N BX4ABC"
   MMDVM.status.val=70
   click S0,1
   t3.txt="TG46001"
   t9.txt="BX4ABC Taro Taipei"
   ```

   畫面應該跟 `mockups/DMR.png` 的下半部一樣。
4. 「文件」→「打开编译文件夹」，裡面的 `tjc8048x550_mmdvm.tft` 就是要燒進螢幕的檔案。

## 7. 把 .tft 放進螢幕

### 方法 A：microSD（建議）

1. 準備一張 32 GB 以下的 microSD，格式化成 **FAT32**。
2. 根目錄**只放一個** `.tft` 檔（有兩個以上螢幕會報錯）。
3. 螢幕斷電，把卡插進螢幕背面的卡槽，再上電（5 V）。
4. 螢幕會顯示更新進度，最後出現更新成功的訊息（`Update Successed!`）。
5. 斷電、拔卡、再上電。應該看到待機頁，中間寫 `WAITING FOR HOST`。

### 方法 B：USB 轉 TTL 線直接接螢幕

1. 螢幕的 XH 4-pin：**1 GND、2 RX、3 TX、4 5V**。USB-TTL 的 TX 接螢幕 RX（2），USB-TTL 的 RX 接螢幕 TX（3），GND 對 GND，5V 對 5V。
   X5 的序列埠是 **5 V 電位**：請用可耐 5 V 的 USB-TTL，或在螢幕 TX → 轉接器 RX 之間串一顆 1 kΩ。
   USB 埠供電不足時（全亮約 330 mA）螢幕另外接 5 V，GND 要共地。
2. 接這條線時，螢幕**不要同時接在熱點板上**。
3. 編輯器按「下载」，選 COM 埠，聯機鮑率選「自动搜索」，下載鮑率選 **921600**（線長或不穩就降到 115200）。這個檔案有好幾 MB，921600 約一兩分鐘。

### 經由 MMDVM 透傳埠：不要用

MMDVM-Display 附的 `NextionUpdater` 有 `Port=modem` 的上傳路徑，但它固定用 9600、沒有流量控制，
MMDVM_HS 韌體的 256 bytes 緩衝滿了會直接丟資料，幾 MB 的檔案傳不完（原因見 `PROTOCOL.md` 第 9 節第 13 點）。

## 8. MMDVM 端的設定

### 8.1 MMDVM-Display（`/etc/MMDVM-Display.ini`）

```ini
[General]
Display=Nextion
TemperatureInF=0

[MQTT]
Host=127.0.0.1
Port=1883
Name=display
HostMQTTName=host
InfoMQTTName=info

[Nextion]
Port=modem
Speed=9600
Brightness=100
DisplayClock=1
UTC=0
ScreenLayout=3
IdleBrightness=30
```

- `Port=modem`：經由 MMDVM 板子的透傳埠（XH 接頭）送給螢幕。
- `ScreenLayout=3`：**一定要是 3**。這個畫面檔的顏色、ERROR／LOCKOUT 顯示都靠版面 3 才有的狀態碼。
  設成 0 或 2 欄位還是會有字，但沒有呼號大字、沒有溫度、ERROR 不會顯示；設成 2 時 DMR 來源還會被改成黑字（看不到）。原因見 `PROTOCOL.md` 第 2 節。
- `Speed`：用 `Port=modem` 時沒有作用，速度由 MMDVM 韌體決定。
- `Brightness` / `IdleBrightness`：通話中／待機時的背光（0–100）。亮度由 MMDVM-Display 控制，螢幕上沒有亮度滑桿。
  **`IdleBrightness` 要寫在 `Brightness` 後面**（程式讀到 `Brightness` 時會把兩個值一起設掉）。
  `Brightness=0` 的意思是「完全不送亮度指令」，不是全暗。
- `HostMQTTName` 要跟 MMDVM-Host 的 `[MQTT] Name=` 一樣（預設都是 `host`）。
- IP、溫度、CPU 這幾格的資料來自 **MMDVM-Info**。沒跑 MMDVM-Info 的話 IP 會是 `(ip unknown)`，LOAD／CPU 是 `?`，TEMP 空白。

### 8.2 時鐘格式：把 LC_TIME 設成 C

時鐘文字是用系統語系產生的。語系若是中文，送出來的是螢幕字型顯示不了的多位元組文字。
在 MMDVM-Display 的 systemd 服務加一行環境變數（服務名稱依你的安裝而定）：

```
sudo systemctl edit mmdvm-display.service
```

```ini
[Service]
Environment=LC_TIME=C
```

存檔後 `sudo systemctl restart mmdvm-display.service`。之後時鐘是 `11/16/26 14:30:00` 這種格式（月/日/年）。

### 8.3 MMDVM-Host

MQTT 版的 MMDVM-Host 不需要任何螢幕設定，它只負責把 `display-in` 的資料轉給數據機（modem）。
確認 `[MQTT] Name=host`，以及 mosquitto 有在跑。

改用 2023-06 以前的舊版 MMDVMHost 時，設定寫在 `MMDVM.ini`：`[Nextion]` `Port=modem`、`ScreenLayout=3`、`Brightness=100`、`IdleBrightness=30`。
同一個畫面檔可以用，差異見 `PROTOCOL.md` 第 8 節。

### 8.4 鮑率（MMDVM_HS 韌體）

- 韌體預設 `SERIAL_REPEATER_BAUD` 是 **9600**，螢幕出廠預設也是 9600：**什麼都不用改就能通。**
- 想加快更新速度，可以重編韌體把 `SERIAL_REPEATER_BAUD` 改成 115200，
  然後在螢幕上按 `SYS` → `115200`。螢幕會記住這個設定（斷電後仍有效）。
- 兩邊鮑率不一樣時螢幕不會更新，但觸控還是有反應，可以再進 `SYS` 頁按回 `9600`。
